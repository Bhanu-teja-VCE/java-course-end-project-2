## 🏏 Project: Campus Premier League (CPL)

The complete Java Course End Project is located in:
👉 **[`Course_End_Project_Java_Campus_Premier_League/`](./Course_End_Project_Java_Campus_Premier_League/)**

### Quick Highlights:
- **Unit I (OOP):** Strict inheritance hierarchy (`Player` &rarr; `Batter`, `Bowler`, `AllRounder`, `WicketKeeper`) with dynamic method dispatch and interfaces (`Rateable`).
- **Unit II (Concurrency & Exceptions):** Live 4-bot auction hall using Java thread monitors (`synchronized`, `wait()`, `notifyAll()`) with zero deadlocks.
- **Unit III (Collections & I/O):** Dynamic collections (`TreeSet`, `HashMap`, `ArrayList`), CSV parsing, and Java Object Serialization for state persistence.
- **Unit IV (Swing & AWT):** High-performance desktop GUI with custom 2D graphics canvases for radial wagon wheels and run-rate worms.
- **Unit V (JDBC):** Dual-mode persistence supporting MySQL 8.0 (stored procedures, callable statements, transactions) and an automatic in-memory fallback for offline grading.
